# 에셋 출처와 교체

| 에셋                            | 출처 / 현재 사용 여부                                                                           |
| ------------------------------- | ----------------------------------------------------------------------------------------------- |
| `public/art/home-room.png`      | 내장 `image_gen`으로 생성 후 만화 스타일로 편집한 실제 집 배경. 최종 선택본을 프로젝트에 복사함 |
| `src/game/home/art.ts`          | 직접 작성한 SVG 캐릭터 파츠와 사물. 당근·그릇·침대 등 실제 Scene 오브젝트에 사용                |
| `src/game/art.ts`, `playArt.ts` | 기존 직접 작성 SVG. 지도·기존 에피소드 및 배경 로딩 실패 시 대체 그림                           |
| 한국어 녹음 / 실제 개 소리      | 미제작. 빈 Manifest 항목만 있음. 임시 사람 TTS도 재생하지 않음                                  |
| 조작 효과음                     | Web Audio로 만든 간단한 음. 실제 개 짖음 녹음이나 고품질 대사를 대신한다고 주장하지 않음        |

외부 게임의 그래픽·캐릭터·로고를 복제하지 않았고, 무료 라이브러리나 유료 상용 에셋을 가져오지 않았습니다. 별도 외부 에셋 라이선스나 구매 비용은 없습니다.

배경은 현재 사용할 일러스트입니다. 캐릭터는 단순 도형 한 개짜리 표시가 아니라 얼굴·머리·팔·다리·몸·꼬리 등 자체 제작 파츠로 구성했습니다. 다만 전문 프레임 작화가 아닌 **절차적 리그 애니메이션**이며, 더 자연스러운 측면 눕기·물기 포즈는 후속 그래픽 개선 대상입니다. 이미지 로딩 실패 때만 사용하는 `home-room-fallback`은 이전 SVG 배경입니다.

## 교체

`src/game/home/assets.ts`의 각 키는 기본적으로 `{svg: ...}`입니다. 예를 들어 당근을 교체할 때 `homeAssets.carrot = {url:'/art/carrot.png'}`로 지정합니다. 같은 중심과 여백, 기준 크기를 유지하면 Scene 동작 코드는 바꾸지 않아도 됩니다. 지니 파츠 교체 시 몸·얼굴은 하얀색, 귀만 갈색이라는 외형과 네 발 구조를 지킵니다. 파일은 `public/art`에 보관하며 장면은 같은 출처에서만 불러옵니다.

## 생성 프롬프트 기록

내장 이미지 도구를 사용했습니다. CLI나 외부 유료 이미지 API를 호출하지 않았습니다. 아래 첫 결과는 재질이 너무 사실적이라 사용하지 않고, 편집 결과를 최종 배경으로 사용했습니다. 원본 생성 파일은 도구의 기본 저장 위치에도 남겨 두었습니다.

### 최초 생성

> Use case: illustration-story. Asset type: actual static background illustration for a portrait mobile preschool free-play game, not a UI mockup. Create a charming hand-painted 2D game living room background in warm cream, sage, peach and honey colors, soft clean detailed storybook forms, gentle dimensional shading. Portrait 3:4 or 2:3 aspect. Straight-on slightly elevated view, upper 45% cozy room wall with big rounded window showing garden, curtain, low pastel sofa on left, small wooden shelf with books and plant upper right. Bottom 55% is a clear spacious honey oak floor with a large soft pale golden oval rug in the lower middle. Clean uncluttered playable floor extending to every edge. NO characters, NO dogs, NO toys on floor, NO pet beds, NO bowls, NO text, NO lettering, NO buttons, NO interface, NO watermark, NO logos. Interactive objects will be layered by game engine. Original art, no existing brand assets. Rounded furniture, fabric texture, natural gentle sunlight, welcoming child scale. Keep bottom corners fairly empty for movable toys and dog bed.

### 최종 편집

입력: 최초 생성한 집 배경을 편집 대상으로 사용.

> Edit this image, maintaining its room layout and completely empty floor. This is a mobile game background, not an interior photograph. Transform it into a flat charming 2D hand-drawn children's cartoon illustration with clean visible soft brown outlines, simplified rounded shapes, large areas of flat pastel color, minimal smooth 2-tone shading. Absolutely remove photorealistic fabric, wood grain, realistic lighting, tiny texture, detailed leaves and physical material rendering. Make it look like a clean professional children's picture-book/game illustration matching simple vector cartoon characters. Pastel cream wall, sage sofa, peach cushion, honey wood floor, pale yellow rug; thick rounded furniture forms. Keep exact portrait composition and upper furniture, huge empty floor lower 55%. No characters, no movable toys, no text, no logo, no UI.
