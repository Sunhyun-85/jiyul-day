# 놀이 화면 개편

## 달라진 흐름

소개 페이지와 긴 이야기 카드 대신 첫 화면을 집·유치원이 있는 그림 지도로 바꿨습니다. 건물을 누르면 방으로 들어가고, 바닥의 놀이 물건을 고르면 이야기가 시작됩니다. 게임 중에는 화면을 스크롤하지 않습니다.

### 지니 돌보기

- 지니를 누르면 짧은 말풍선과 움직임으로 상황을 보여 줍니다. 배고플 때는 밥그릇으로, 목마를 때는 물그릇으로, 산책하고 싶을 때는 문 쪽으로 몸을 움직입니다.
- 관찰 시간이 지난 뒤 나무 선반에 놀이 물건이 나옵니다. 물건의 순서는 매번 섞이며 부모의 선택지 개수 설정도 유지됩니다.
- 사료 봉지를 밥그릇에, 물병을 물그릇에, 목줄을 문으로 끌어놓을 수 있습니다. 끌기가 어려우면 물건을 한 번 누르고 목적지를 누릅니다.
- 목적지가 아닌 곳에 놓으면 선반으로 돌아옵니다. 이 경우 행동 기록이나 실패 판정을 만들지 않습니다.
- 물건을 맞는 목적지에 놓아도 지니의 필요와 다르면 상황은 계속됩니다. 예를 들어 목마른 지니에게 밥을 주면 목마름 신호가 유지됩니다.
- 밥알·물방울, 그릇 채움, 지니의 먹는 움직임으로 반응합니다. 산책은 어른이 등장한 뒤 함께 문 쪽으로 이동합니다.

### 나머지 이야기

공 찾기는 소파·상자·문을 직접 눌러 살펴보거나 선반의 그림으로 같은 행동을 할 수 있습니다. 블록 놀이는 집 블록을 바닥에 놓고 함께 쌓거나 번갈아 놓는 반응을 보여 줍니다. 친구 마음 듣기는 도움 손·하트·쉬는 쿠션 그림으로 대화하며, 거절 후 다른 행동을 고르는 분기는 유지합니다.

친구 놀이의 모든 대화를 자유 조작으로 바꾼 것은 아닙니다. 제안·질문·듣기·기다리기 같은 사회적 의도는 그림을 눌러 표현합니다. 공의 물리 운동, 자유로운 블록 쌓기나 캐릭터 자유 이동은 구현 범위에 포함하지 않습니다.

## 글과 음성

기본 화면에는 짧은 말풍선만 표시합니다. 원래 대사 전체는 음성으로 안내하며, 왼쪽 대사 버튼을 누르면 펼쳐 볼 수 있습니다. 부모 설정의 **전체 대사 자막**으로 항상 표시할 수도 있습니다. 음성이 없는 환경에서도 그림·직접 조작으로 진행할 수 있고, 펼친 대사 화면에서 부모가 읽어 줄 수 있습니다.

긴 설명형 완료 화면은 없애고 같은 방에서 짧게 반응한 뒤 **또 놀자 / 다른 놀이**로 이어집니다. 반응은 보통 속도에서 3.5초, 느림에서 5.5초 후 다음 단계로 넘어갑니다. 선택을 재촉하는 시간 제한은 없습니다. 전체 자막을 켜면 읽는 시간을 늘리고, 부모 설정 또는 전체 대사 패널을 열면 자동 진행을 멈춥니다. 화살표로 바로 이어갈 수도 있습니다.

## 구현과 기록

- `WorldMap.tsx`: 그림 지도와 방 안의 놀이 선택.
- `GameUI.tsx`: 말풍선, 물건 선반, 목적지, 결과 효과, 짧은 마무리.
- `DraggableToy.tsx`: 포인터 캡처, 끌어놓기와 두 번 누르기, 잘못 놓았을 때 복귀.
- `playState.ts`: 물건과 목적지 의미 연결, 놓은 위치 판정.
- `GameScene.ts`: 화면 크기에 맞춘 Phaser 장면, 상황별 접근·표정·터치 반응.
- `playArt.ts`: 배경·건물·물건의 직접 제작 SVG.
- `SoundEffects.ts`: 외부 파일 없이 합성하는 작은 조작 소리.
- JSON의 `shortLine`, `cueIcon`, `shortResult`: 짧은 대사와 그림 단서. 원래 대사·행동 ID·분기는 그대로 유지합니다.
- 선택 기록의 선택적 `input` 필드: `tap` 또는 `drag`. 기존 IndexedDB 기록은 그대로 읽을 수 있습니다.

물건 사용 방법을 알려 주는 목적지 테두리는 현재 집어 든 물건의 목적지를 표시합니다. 지니가 무엇을 원하는지를 정답 표시로 알려 주는 것은 아닙니다. 상황 힌트는 부모 설정에서 허용한 힌트 버튼을 눌렀을 때만 별도로 표시하고 기록합니다.

## 재배포

기존 배포 주소는 파일 수정만으로 바뀌지 않습니다. 새 빌드의 `jiyul-day-upload-v2.zip`을 태블릿으로 다운로드한 뒤, 기존 Cloudflare Pages 프로젝트에서 **Create a new deployment**로 올리면 됩니다. 기존 `jiyul-day-upload.zip`은 이전 버전으로 남겨 두었습니다.

사이트에서 새 버전 알림을 받으면 놀이를 마친 뒤 **새 버전 열기**를 누릅니다. 동일한 배포 주소를 사용하면 설정과 기록이 유지됩니다.
