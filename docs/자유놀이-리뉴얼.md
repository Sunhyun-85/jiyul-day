# 우리 집 자유놀이 — 1.2.0

## 기존 프로젝트와 체크포인트

React 19 + TypeScript + Phaser 3.90 + Vite 프로젝트를 유지했습니다. 기존 ScenarioEngine, VariationEngine, DialogueEngine, 네 에피소드의 ID와 행동 분기, localStorage 설정, IndexedDB 버전 1과 기존 레코드를 보존합니다. 시작 전 체크포인트는 `7f918d6`입니다. 대규모 교체나 데이터 삭제 없이 집 자유놀이 Scene과 파일 음성 계층을 추가했습니다. 새 서비스 구매·유료 API 호출은 없습니다.

## 놀이 방법

1. 지도에서 **우리 집**을 누르면 바로 자유놀이 거실로 들어갑니다. 에피소드 선택이나 관찰 타이머를 거칠 필요가 없습니다.
2. 당근 인형을 끌어 바닥에 놓습니다. 끌기 어려우면 인형을 누른 뒤 놓을 곳을 누릅니다. 같은 인형을 다시 눌러 제자리에서 놀이를 시작할 수도 있습니다.
3. 놀고 싶은 지니는 다가가 당근을 물고 지율이에게 돌아옵니다. 입의 당근이나 지니를 누르면 지율이가 받아 듭니다. 다시 바닥에 놓아 놀이를 이어갑니다.
4. 사료 봉지를 밥그릇에 끌어놓거나 봉지 → 그릇을 누릅니다. 물그릇을 누르면 물이 채워지고 지니가 다가와 마십니다. 물병을 끌어놓는 방법도 됩니다.
5. 침대를 누르면 지니가 쉬고, 지니를 누르면 쓰다듬습니다. 빈 바닥을 누르거나 지율이를 끌면 지율이가 이동합니다. 상자를 누르면 뚜껑이 열립니다.
6. 오른쪽 아래 **책 그림**은 기존 집 이야기 두 개로 이어집니다. 지도에서 유치원으로 들어가면 기존 하우리 이야기 두 개를 계속 플레이합니다.

정답 카드, 점수, 필수 순서, 성공해야 열리는 단계는 집 자유놀이에 없습니다. 공 찾기는 기존 이야기로 남겨 두었으며, 새 집 놀이의 대표 물건은 당근 인형입니다.

## 상태와 반응

`CharacterStateEngine`은 배고픔·갈증·기운을 0–100으로 유지하고, 이 값으로 욕구와 기분을 계산합니다. 수치는 부모 기록용 데이터이며 아이 화면에 점수처럼 표시하지 않습니다.

- 에너지 25 이하: 하품·눈 감기·휴식 단서, 당근보다 침대로 이동.
- 갈증 65 이상: 물그릇 단서. 배고픔도 높으면 더 높은 요구를 우선하되 심한 피로가 먼저입니다.
- 배고픔 65 이상: 밥그릇 단서, 당근보다 그릇으로 이동.
- 그 외: 꼬리 흔들기와 당근 단서, 인형 가져오기.
- 인형 한 번 가져오기: 에너지 −9, 배고픔 +6, 갈증 +9.
- 식사 완료: 배고픔 −70. 마시기 완료: 갈증 −75. 휴식 완료: 에너지 +55.

값은 실제 동작이 끝날 때만 바뀝니다. 이동 중 다른 행동으로 바뀌면 이전 완료 콜백을 무효화합니다. 앱을 닫아 둔 시간에 욕구가 나빠지거나, 이유 없이 행동을 거절하지 않습니다. 재입장 시 VariationEngine이 최근 방문 이력을 보고 다른 시작 상황을 고르고, 당근·지니의 위치와 설명 표현도 섞습니다. 한 번의 놀이 안에서는 상태의 인과관계가 유지됩니다.

## 그래픽과 애니메이션

현재 쓰는 배경 PNG는 내장 이미지 도구로 생성한 원본 일러스트이고, 캐릭터·당근·그릇 등은 직접 작성한 SVG입니다. 외부 게임 에셋이나 유료 에셋은 사용하지 않았습니다. 생성 과정과 에셋 교체 방법은 [에셋 기록](에셋.md)에 있습니다.

지니의 몸·얼굴·발·꼬리는 하얗고, 털 중 갈색은 귀에만 있습니다. 검은 눈과 코는 얼굴 특징입니다. 몸통과 네 발, 머리, 눈, 꼬리를 분리해 걷기·달리기·먹기·마시기·물기·꼬리 흔들기·눕기·잠자기를 표현합니다. 사람처럼 말하거나 두 발로 걷지 않습니다. 지율이는 다리·팔·머리를 분리해 이동, 인형 들기, 손 흔들기 등을 표현합니다.

전문 애니메이터가 제작한 프레임별 스프라이트 시트는 아직 없으며 **파츠 변형으로 구현한 애니메이션**입니다. 잠자기와 눕기는 파츠를 낮추는 단순 포즈로, 전용 측면 작화처럼 정교한 동작은 후속 개선 대상입니다. 하우리의 기존 표정·반응은 유지하며, 유치원의 자유 블록 물리놀이는 이번 범위에 포함하지 않습니다.

## 모바일과 접근성

720 단위의 논리 좌표와 Phaser FIT를 사용하고, 긴 세로 화면에서는 논리 높이와 카메라를 확장해 배경이 화면을 채웁니다. 캐릭터를 세로로 늘리지 않습니다. 화면 회전 시 물건 상태와 위치를 유지합니다. 당근 등 작은 물건은 그림보다 넓은 터치 영역을 제공합니다. 가로 화면은 놀이 공간의 비율을 보존합니다.

탭 후 목적지 탭, 키보드로 선택 가능한 숨김 조작, 자막 설정, 시스템의 동작 줄이기를 지원합니다. 부모 창이나 백그라운드에서는 Scene을 정지합니다. Android 실기기에서의 손가락 감각·주소창 변화·음량은 실제 기기로 추가 확인해야 합니다.

## 음성 상태

파일 재생 구조와 도구는 구현했습니다. **실제 자연스러운 한국어 녹음과 실제 개 효과음은 아직 0개입니다.** 브라우저 TTS를 대체 음성으로 실행하지 않습니다. 파일이 없으면 움직임·그림·짧은 자막으로 놀이합니다. 합성 조작음은 임시 내레이션이 아니라 탭·반응을 알려 주는 간단한 효과음입니다. [음성 제작 안내](음성-제작.md)를 보고 녹음을 추가할 수 있습니다.

## 실행과 배포

프로젝트 폴더에서 `npm ci`, `npm run dev`로 실행합니다. 검증은 `npm test`, `npm run build`, `npm run test:e2e`입니다. 빌드 후 `npm run preview`로 배포 파일을 확인합니다.

Cloudflare에는 새 프로젝트를 만들 필요가 없습니다. `jiyul-day-upload-v3.zip`을 code-server 파일 목록에서 내려받고, 기존 Pages 프로젝트의 **새 배포 만들기 / Create a new deployment → Production**에 올립니다. [Cloudflare 공식 안내](https://developers.cloudflare.com/pages/get-started/direct-upload/)에서 확인한 기존 Direct Upload 프로젝트의 새 배포 방식입니다. ZIP 안의 최상위에 `index.html`이 있어야 합니다. 기존 ZIP은 보관합니다. 같은 주소를 사용하면 기기의 설정과 기록을 유지할 수 있습니다. 새 버전 안내는 놀이 밖에서 표시됩니다. 로컬 수정만으로 이미 배포된 사이트가 바뀌지는 않습니다.
